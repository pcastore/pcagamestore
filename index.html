Order နှင့် ပေးပို့မှု
ငွေပေးချေမှု အတည်ပြုပြီးသည်နှင့် Order များကို အလိုအလျောက် လုပ်ဆောင်ပါသည်။ ပေးပို့ချိန်မှာ game/voucher provider ပေါ်မူတည်ပြီး များသောအားဖြင့် ချက်ချင်းမှ မိနစ်အနည်းငယ်အထိ ကြာနိုင်ပါသည်၊ တချို့ order များကို admin မှ manual စစ်ဆေးရန် လိုအပ်နိုင်ပါသည်။
ငွေပေးချေမှု
Kpay/Wave/etc (ပြေစာတင်ရန်)၊ Wallet လက်ကျန်ငွေ၊ Crypto/USDT top-up အပါအဝင် manual ငွေပေးချေမှု နည်းလမ်းများကို လက်ခံပါသည်။ ငွေပေးချေရာတွင် မှန်ကန်သော အချက်အလက်များကို အသုံးပြုရပါမည်။ In-Game ID၊ Server ID၊ သို့မဟုတ် ငွေပေးချေမှု အထောက်အထားများ မှားယွင်းစွာ တင်ထားသော order များကို နှောင့်နှေးခြင်း သို့မဟုတ် ပယ်ချခြင်း ဖြစ်နိုင်ပါသည် — ထိုသို့ဖြစ်ပါက ဘာဖြစ်မည်ကို Refund tab တွင် ကြည့်ပါ။
Account နှင့် Wallet
သင်၏ account အချက်အလက်များကို မှန်ကန်စွာ ထားရှိရန် သင့်တွင် တာဝန်ရှိပါသည်။ Wallet လက်ကျန်ငွေသည် သင်၏ account/guest ID နှင့် ချိတ်ဆက်ထားပြီး account တစ်ခုမှ တစ်ခုသို့ လွှဲပြောင်း၍ မရပါ၊ ဤ store တွင် ဝယ်ယူမှုများအတွက်သာ အသုံးပြု၍ ရပါသည်။
တရားမျှတသော အသုံးပြုမှု
Promotion များကို အလွဲသုံးစားလုပ်ခြင်း၊ chargeback လုပ်ခြင်း၊ သို့မဟုတ် လိမ်လည်သော ငွေပေးချေမှု အထောက်အထားများ တင်ခြင်းသည် order ပယ်ဖျက်ခြင်း သို့မဟုတ် account ကန့်သတ်ခြင်းသို့ ဦးတည်နိုင်ပါသည်။
ဤစည်းကမ်းချက်များ ပြောင်းလဲခြင်း
Store တိုးတက်လာသည်နှင့်အမျှ ဤစည်းကမ်းချက်များကို ကျွန်ုပ်တို့ update လုပ်နိုင်ပါသည်။ update လုပ်ပြီးနောက် ဆက်လက် အသုံးပြုခြင်းသည် ပြင်ဆင်ထားသော စည်းကမ်းချက်များကို သဘောတူလက်ခံရာ ရောက်ပါသည်။
ဆက်သွယ်ရန်
ဤစည်းကမ်းချက်များနှင့် ပတ်သက်၍ မေးခွန်းများ ရှိပါက Telegram @pca_gamestore သို့မဟုတ် Profile စာမျက်နှာရှိ Support button မှတစ်ဆင့် ဆက်သွယ်နိုင်ပါသည်။
မည်သည့်အချက်အလက်များ စုဆောင်းသနည်း
သင်၏ account ကို ခွဲခြားသိရှိရန် device/guest ID၊ သင်ထည့်သွင်းရွေးချယ်သော profile အချက်အလက်များ (အမည်၊ ဖုန်းနံပါတ်)၊ Google ဖြင့် login ဝင်ပါက သင်၏ Google အမည်/ဓာတ်ပုံ၊ order တစ်ခုစီအတွက် ထည့်သွင်းသော In-Game ID/Server ID၊ manual top-up များအတွက် ငွေပေးချေမှု ပြေစာပုံများ၊ နှင့် သင်၏ order/wallet top-up မှတ်တမ်းများကို စုဆောင်းပါသည်။
အဘယ်ကြောင့် စုဆောင်းသနည်း
သင်၏ order နှင့် top-up များကို လုပ်ဆောင်ရန်၊ ငွေပေးချေမှုများကို စစ်ဆေးရန်၊ In-game item များကို မှန်ကန်သော account သို့ ပေးပို့ရန်၊ wallet စနစ်ကို လည်ပတ်ရန်၊ နှင့် support တောင်းဆိုမှုများကို ဖြေကြားရန်အတွက်သာ အသုံးပြုပါသည်။ သင်၏ အချက်အလက်များကို ကြော်ငြာအတွက် အသုံးမပြုပါ။
မည်မျှကြာ သိမ်းဆည်းထားသနည်း
ပြီးစီးသွားသော order နှင့် wallet top-up မှတ်တမ်းများ (Success/Fail သို့မဟုတ် Completed/Rejected) ကို ၇ ရက်အကြာတွင် အလိုအလျောက် ဖျက်ပစ်ပါသည်။ Pending/Processing အခြေအနေရှိ order များကို ပြီးဆုံးသည်အထိ ထားရှိပါသည်။ သင်၏ profile အချက်အလက် (အမည်၊ ဖုန်း၊ wallet လက်ကျန်) ကို သင်၏ account/guest ID အသက်ဝင်နေသရွေ့ ထားရှိပါသည်။
မျှဝေခြင်း
သင်၏ ကိုယ်ရေးအချက်အလက်များကို ကျွန်ုပ်တို့ ရောင်းချခြင်း မပြုပါ။ ငွေပေးချေမှု ပြေစာများနှင့် top-up အသေးစိတ်ကို သင်၏ငွေပေးချေမှုကို အတည်ပြုရန်အတွက်သာ အတွင်းပိုင်းတွင် အသုံးပြုပါသည်၊ crypto top-up များကို သင်ပေးပို့သော public blockchain network ပေါ်တွင် စစ်ဆေးပါသည်။
ကြည့်ရှုခွင့်နှင့် ဖျက်ပစ်ခွင့်
သင့်အကြောင်း ကျွန်ုပ်တို့ ဘာအချက်အလက်များ ထားရှိသည်ကို မေးမြန်းလိုပါက သို့မဟုတ် သင်၏ profile နှင့် history ကို ဖျက်ပစ်ပေးရန် တောင်းဆိုလိုပါက Telegram @pca_gamestore သို့ အချိန်မရွေး message ပို့နိုင်ပါသည်၊ ဖြေရှင်းရန်ကျန်နေသေးသော order/ငွေပေးချေမှု အငြင်းပွားမှုအတွက် သီးခြား မှတ်တမ်းများ ထိန်းသိမ်းထားရန် လိုအပ်ခြင်း မရှိပါက ဖြစ်သည်။
ကလေးများ
ဤ store သည် အသက်ငယ်ရွယ်သော ကလေးများအတွက် ရည်ရွယ်ထားခြင်း မဟုတ်ပါ။ သင်၏ နိုင်ငံ၏ ဥပဒေအရ အာဏာပိုင်၏ ကြီးကြပ်မှု မရှိဘဲ online ငွေပေးချေမှု ပြုလုပ်ရန် အသက်မပြည့်သေးပါက ကျေးဇူးပြု၍ မိဘ/အုပ်ထိန်းသူနှင့်အတူသာ ဤဝန်ဆောင်မှုကို အသုံးပြုပါ။
ဤမူဝါဒ ပြောင်းလဲခြင်း
Store တိုးတက်လာသည်နှင့်အမျှ ဤ Privacy Policy ကို ကျွန်ုပ်တို့ update လုပ်နိုင်ပါသည်။ update လုပ်ပြီးနောက် ဆက်လက်အသုံးပြုခြင်းသည် ပြင်ဆင်ထားသော မူဝါဒကို သဘောတူလက်ခံရာ ရောက်ပါသည်။
ဆက်သွယ်ရန်
ကိုယ်ရေးအချက်အလက်နှင့် ပတ်သက်သော မေးခွန်းများအတွက် Telegram @pca_gamestore သို့ ဆက်သွယ်နိုင်ပါသည်။
အောင်မြင်သော Order များ
Order တစ်ခု Success ဖြစ်ပြီး item ကို ပေးပို့ပြီးသည်နှင့် ၎င်းသည် အပြီးသတ်ဖြစ်ပြီး ငွေပြန်အမ်းပေးမည် မဟုတ်ပါ — In-Game ID သို့မဟုတ် Server ID ကို သင်ကိုယ်တိုင် မှားယွင်းစွာ ထည့်ခဲ့ခြင်းလည်း အပါအဝင်ဖြစ်ပြီး၊ ထို account သို့ digital ပေးပို့မှုကို ပြန်ပြင်၍ မရနိုင်တော့ပါ။ ကျေးဇူးပြု၍ အတည်ပြုမလုပ်မီ သင်၏ ID ကို နှစ်ကြိမ်စစ်ဆေးပါ။
မအောင်မြင်သော Order များ
Order တစ်ခု fail ဖြစ်ပါက (ဥပမာ provider က ပေးပို့နိုင်ခြင်း မရှိပါက) order ပမာဏကို သင်၏ Wallet လက်ကျန်ငွေထဲသို့ ပြန်အမ်းပေးပါမည်၊ များသောအားဖြင့် order ကို Failed အဖြစ် သတ်မှတ်ပြီး ၂၄ နာရီအတွင်း ဖြစ်ပါသည်။ ထို လက်ကျန်ငွေကို နောက် order တစ်ခုအတွက် ပြန်သုံးနိုင်ပါသည်။
Order တစ်ခု ပယ်ဖျက်ခြင်း
Pending အခြေအနေရှိနေသေးသော order များကို Support ကို ဆက်သွယ်ခြင်းဖြင့် ပုံမှန်အားဖြင့် ပယ်ဖျက်၍ ရပါသည်။ Order တစ်ခု Processing (game/voucher provider ထံ ပို့ပြီးသား) အခြေအနေသို့ ရောက်သွားပါက နောက်ထပ် ပယ်ဖျက်၍ မရတော့ပါ။
Manual Top-Up များ (Kpay/Wave/etc.)
Manual top-up တောင်းဆိုမှုတစ်ခုကို ပယ်ချခံရပါက (ဥပမာ ပြေစာ မရှင်းလင်းခြင်း သို့မဟုတ် မမှန်ကန်ခြင်းကြောင့်) Wallet လက်ကျန်ငွေ ဘာမှ ထည့်ပေးမည် မဟုတ်ပါ — ငွေသည် ကျွန်ုပ်တို့၏ Wallet စနစ်ကို ဘယ်တော့မှ ဖြတ်မသွားခဲ့ပါ၊ ကျေးဇူးပြု၍ သင်၏ ငွေပေးချေမှု app ၏ transaction မှတ်တမ်းကို ထားရှိပြီး ပယ်ချမှုသည် အမှားဖြစ်သည်ဟု ယုံကြည်ပါက Support ကို ဆက်သွယ်ပါ။

Blockchain transaction များသည် ပြန်ပြင်၍ မရပါ။ App ထဲတွင် ပြသထားသော မှန်ကန်သော ပမာဏနှင့် မှန်ကန်သော network ပေါ်တွင် ပေးပို့ကြောင်း ကျေးဇူးပြု၍ အတည်ပြုပါ။ လိပ်စာမှား၊ network မှား၊ သို့မဟုတ် ပမာဏမှား ပေးပို့မိသော ငွေများကို ကျွန်ုပ်တို့ ပြန်ယူပေး၍ မရနိုင်ပါ။
Wallet လက်ကျန်ငွေ
Wallet လက်ကျန်ငွေကို ဤ store တွင် ဝယ်ယူမှုများအတွက်သာ အသုံးပြု၍ ရပြီး ငွေသားအဖြစ် ထုတ်ယူ၍ မရ၊ အခြား account သို့ လွှဲပြောင်း၍ မရပါ — ကျွန်ုပ်တို့ ဖြေရှင်းလိုသော ပြဿနာအတွက် သီးခြား ရွေးချယ်သည့်အခါမှလွဲ၍။
အငြင်းပွားမှုတစ်ခု ဖော်ပြနည်း
သင်၏ Order ID သို့မဟုတ် Top-Up ID ဖြင့် Telegram @pca_gamestore ကို အမြန်ဆုံး ဆက်သွယ်ပါ — ၇ ရက်အတွင်း ဆက်သွယ်ရန် အကောင်းဆုံးဖြစ်ပါသည်၊ အကြောင်းမှာ ၇ ရက်ထက်ကြာသော order/top-up မှတ်တမ်းများကို ကျွန်ုပ်တို့၏ မှတ်တမ်းများမှ အလိုအလျောက် ဖျက်ပစ်လိုက်ပါသည်။
